
# NEXORA AI
### Smart Retail Intelligence & Decision Support System

NEXORA AI is a retail intelligence platform designed to help businesses analyze sales and inventory data and make data-driven decisions.

## Problem Statement
Retail businesses need an efficient way to monitor inventory, identify stock risks, and understand sales performance.

## Key Features
- Retail data analysis using CSV and Excel files
- Sales and inventory KPI dashboard
- Low-stock monitoring
- Inventory and expiry analysis
- Category and supplier insights
- Data quality analysis

## Technology Stack
- Python
- FastAPI
- React
- Vite
- Pandas

## Project Structure
- `backend/` - Backend and data processing
- `data/` - Project dataset
- `nexora-frontend/` - Frontend application
